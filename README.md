# 鹿兒島家族自駕遊｜9/27–10/6

手機版旅遊 App，採用純 HTML + CSS + JavaScript，無需 npm、Vercel 或建置工具，可直接部署到 GitHub Pages。

## GitHub Pages

在 GitHub Repository → **Settings → Pages**：

1. Source 選 **Deploy from a branch**
2. Branch 選 **main**
3. Folder 選 **/(root)**
4. Save

網站網址會是：
`https://mushroomvicky95.github.io/9.27-10.6new/`

## 功能

- 📅 9天行程總覽與逐日時間軸
- 🎟️ 自由活動／餐飲選擇集中整理
- 📋 出發前必備清單，可打勾並儲存在本機瀏覽器
- ✈️ 航班與交通重點
- 💬 FAQ 搜尋
- 📱 手機優先介面，底部五分頁設計

行程資料以使用者提供的「鹿兒島自駕遊行程表」為基礎；原表中 4/10 返港人數有兩處不同文字，App 保留原資訊並在 FAQ 提醒核對。
